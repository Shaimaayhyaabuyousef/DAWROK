# نقل حسابات دورك إلى الدخول بالهاتف

يدخل المواطن وصاحب المنشأة والموظف برقم جوال فلسطيني وكلمة مرور. يقبل التطبيق 059 و056 والصيغة الدولية +970 والأرقام العربية. يستخدم Firebase Auth مزوّد Email/Password داخليًا مع معرّف غير قابل للمراسلة مشتق من الرقم. لا يرسل التطبيق بريدًا أو SMS. أرقام التواصل في الملف الشخصي منفصلة عن رقم الدخول. محاكاة استعادة الحساب تعرض رمزًا محليًا صالحًا لدقيقة، ولا تمنح جلسة ولا تغيّر كلمة المرور. يتولى مسؤول مخوّل الاستعادة الحقيقية بعد التحقق من صاحب الحساب.

## الترحيل قبل توزيع النسخة

نفّذي الأوامر على جهاز إدارة موثوق لديه صلاحية Firebase Admin في dawrok-f908e. أغلقي التسجيل وقت الانتقال حتى لا ينشئ مستخدم جديد حسابًا برقم مطلوب لحساب قديم. احتفظي بنسخة احتياطية آمنة من حسابات Auth وبيانات المشروع وخارج Git. يجب أن يكون ملف الأرقام خاصًا، ولا تشاركيه في الدردشة.

من جذر المشروع في PowerShell:

```powershell
cd scripts
npm install
$map = Join-Path $env:TEMP 'dawrok-phone-migration.json'
node migrate_phone_logins.mjs --inventory | Out-File -Encoding utf8 $map
```

راجعي كل UID ورقم مقترح مع صاحب الحساب. رقم هاتف المنشأة العام قد يختلف عن رقم دخول المالك، وقد يكون رقم التواصل في ملف المواطن قد تغيّر. للحسابات التي لم تدخل من قبل بكلمة مرور، حددي لكل حساب كلمة مرور أولية مستقلة وسلّميها لصاحبه بقناة خاصة. ضعيها في متغير بيئة خاص بذلك الحساب واكتبي اسم المتغير فقط في خاصية passwordEnv في صفه. استخدمي reviewed بقيمة true بعد المراجعة. عند تعارض رقمين، عيّني رقمين مختلفين. لا تدمجي الحسابين.

```powershell
node migrate_phone_logins.mjs $map
```

بعد نجاح المعاينة وفي نافذة الصيانة:

```powershell
node migrate_phone_logins.mjs $map --apply
```

تستخدم الأداة updateUser على UID الأصلي. تحتفظ حسابات كلمة المرور بكلماتها الحالية. تعالج الأداة جميع صفحات حسابات Auth، وتفحص التعارضات قبل الكتابة. إذا توقّف التنفيذ جزئيًا أعيدي تشغيل المعاينة ثم التطبيق بنفس الملف. لا تعدّل الأداة الحجوزات أو النقاط أو عضويات الموظفين. سجّلي الدخول بحساب معروف من كل دور وتحققي من البيانات القديمة قبل فتح التسجيل مجددًا. إن كانت مزوّدات Google وFacebook وTwitter مفعّلة في Firebase Authentication، عطّليها من Sign-in method بعد اكتمال انتقال أصحاب الحسابات الاجتماعية. اتركي Email/Password مفعّلًا.

لإنشاء منشأة جديدة استخدمي رقم دخول المالك مكان البريد في الأمر المعتاد:

```powershell
node provision_facility.mjs 0591234567 "Example Bank" bank
```

تُقرأ كلمة مرور المنشأة من متغير DAWROK_FACILITY_PASSWORD.
