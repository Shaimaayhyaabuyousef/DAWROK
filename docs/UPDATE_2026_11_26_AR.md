# تحديث 26 نوفمبر 2026

## رقم هوية واحد لكل حساب
- مجموعة جديدة `national_id_claims/{nationalId}` تُكتب في دفعة التسجيل نفسها. القواعد تمنع إنشاءها مرتين، وتشترط وجودها عند إنشاء `citizen_identity`.
- يُفحص رقم الخانة التاسعة (رقم التحقق) في رقم الهوية عند التسجيل.
- للحسابات القديمة: `cd scripts && node migrate_national_id_claims.mjs` (معاينة) ثم `--apply`. الأرقام المكررة تُعرض ولا تُحجز، وتراجعينها يدويًا.

## تنبيه الدور و«قبلك X أشخاص»
- عند الاستدعاء يكتب التطبيق `facilities/{fid}/queues/{qid}/progress/{dayKey}` = رقم الدور المنادى عليه. يقرؤه المواطن فقط ولا يرى تذاكر غيره.
- «قبلك X أشخاص» = رقم دوري − رقم الدور الجاري − 1 (تقديري؛ الأولوية والتأجيل والإلغاء تغيّره).
- يظهر شريط تنبيه أعلى أي شاشة مع اهتزاز وصوت عند الاستدعاء ("حان دورك، توجّه إلى الشباك N")، وتنبيه عندما يتبقى شخصان أو أقل.
- التنبيه داخل التطبيق فقط. الإشعار خارج التطبيق (push) يحتاج Firebase Cloud Messaging مع خادم يرسل الإشعار (Cloud Functions على خطة Blaze).

## العربية والإنجليزية
- اختيار اللغة في أول شاشة تعريف، ومن الإعدادات لاحقًا. يُحفظ الاختيار على الجهاز.
- كل نصوص الواجهة تمر عبر `tr()` في `lib/l10n/app_language.dart`، والترجمة في `lib/l10n/ar.dart`. أي نص جديد: اكتبيه بالإنجليزية داخل `tr('...')` وأضيفي ترجمته.
- العربية تقلب الاتجاه بالكامل (RTL): الهوامش والمحاذاة والمواقع صارت اتجاهية (Directional)، والأسهم تنقلب تلقائيًا. الأرقام وحقول الهاتف والهوية تبقى بالأرقام الإنجليزية.
- الخط العربي: IBM Plex Sans Arabic (ترخيص OFL في `assets/fonts`)، ويبقى Inter للنص اللاتيني والأرقام.
- معاينة الشاشات باللغتين: `flutter test --update-goldens test_preview` ثم الصور في `test_preview/goldens`.
